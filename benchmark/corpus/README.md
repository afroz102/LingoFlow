# corpus/

Empty until Stage 0B. This will hold the versioned 450–700 item English/Devanagari-Hindi/Hinglish
benchmark corpus, including the adversarial meaning-reversal subset, per
[VALIDATION_PLAN.md §4.1](../../docs/VALIDATION_PLAN.md#41-corpus). Do not populate it ahead of Stage
0B — Stage 0A's stub provider has no use for it, and freezing it early would pre-empt the
Stage 0B corpus-design step in [IMPLEMENTATION_PLAN.md §3](../../docs/IMPLEMENTATION_PLAN.md#3-stage-0b--freeze-the-benchmark-protocol).
